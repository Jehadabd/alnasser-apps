# GPS Link — الهاتف كجهاز GPS لـ Google Earth Pro عبر كابل USB

```
[الهاتف: مرسل] --USB (adb)--> [الكمبيوتر: مستقبل] --> COM5 ==com0com==> COM6 --> Google Earth Pro
```

## ١) تجهيز الكمبيوتر (مرة واحدة)
1. **Python 3.12** من python.org (فعّل خيار *Add to PATH*).
2. **adb**: نزّل *SDK Platform-Tools for Windows* من موقع Android Developers، وفك الضغط بحيث يصبح عندك المجلد
   `gps\platform-tools\adb.exe` بجانب `main.py`.
3. **com0com** (منفذ COM وهمي): ثبّت النسخة الموقّعة **2.2.2.0 x64** من SourceForge.
   بعد التثبيت افتح *Setup Command Prompt* من قائمة ابدأ (كمسؤول) واكتب:
   ```
   change CNCA0 PortName=COM5
   change CNCB0 PortName=COM6
   ```
   برنامجنا يكتب على **COM5**، وGoogle Earth يقرأ من **COM6** تلقائياً.

## ٢) تجهيز الهاتف (مرة واحدة)
1. الإعدادات ← حول الهاتف ← اضغط **رقم الإصدار (Build number)** 7 مرات.
2. خيارات المطوّر ← فعّل **تصحيح USB (USB debugging)**.
3. ثبّت ملف `GPS Link.apk` (طريقة بنائه في القسم ٥).

## ٣) التشغيل
1. وصّل الهاتف بالكابل ← على الهاتف اضغط **سماح** لنافذة تصحيح USB.
2. الهاتف: افتح التطبيق ← **مرسل** ← اسمح بالموقع. (أبقِ التطبيق مفتوحاً والشاشة تعمل).
3. الكمبيوتر: شغّل `run_receiver.bat` ← **مستقبل** ← اختر COM5 ← **تشغيل**.
   - أخضر «نجح الاتصال — الموقع يصل» = كل شيء يعمل.
   - افصل الكابل ← يظهر خلال ثوانٍ «انقطع الاتصال / انقطعت الإشارة» على الكمبيوتر والهاتف معاً.
4. Google Earth Pro ← Tools ← GPS ← Realtime ← NMEA ← **Start**.

## ٤) اختبار بدون هاتف
`run_demo.bat` يحاكي هاتفاً يمشي في دائرة ببغداد ويرسل إلى COM5 — لتتأكد أن com0com وGoogle Earth يعملان قبل الهاتف.

## ٥) بناء تطبيق الأندرويد (APK)
Buildozer لا يعمل على ويندوز مباشرة. أسهل طريق:
- ارفع مجلد `gps` إلى مستودع على GitHub، وانقل الملف `build-apk.yml` إلى المسار `.github/workflows/build-apk.yml` (من GitHub: Add file ← Create new file واكتب هذا المسار والصق المحتوى) ← تبويب **Actions** ← *Build Android APK* ← بعد ~20–40 دقيقة نزّل `GPS-Link-APK` من أسفل صفحة التشغيل.
- أو داخل WSL (Ubuntu): `pip install buildozer cython==0.29.37` ثم `buildozer android debug`.

## حالات الشاشة
| الحالة | المعنى |
|---|---|
| بانتظار توصيل الهاتف | لا يوجد هاتف على USB |
| الهاتف موصول لكن غير مصرّح | اضغط «سماح» على الهاتف |
| تم التعرف على الهاتف | التطبيق على الهاتف ليس في وضع «مرسل» |
| تم الاتصال بالهاتف | الهاتف يبحث عن الأقمار |
| نجح الاتصال — الموقع يصل | يعمل |
| انقطع الاتصال / انقطعت الإشارة | الكابل فُصل أو أُغلق التطبيق |
| تعذّر فتح منفذ COM | com0com غير مثبت أو المنفذ خطأ |
